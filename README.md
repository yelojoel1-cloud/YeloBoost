# YeloBoost

**YeloBoost** est une application qui permet de booster vos réseaux sociaux facilement.

## Fonctionnalités
- Gestion de plusieurs comptes
- Augmentation de visibilité et d'interactions
- Téléchargement simple et rapide de l'APK

## Installation
1. Télécharger le fichier [YeloBoost.apk](https://github.com/ton-utilisateur/YeloBoost/raw/main/YeloBoost.apk
).
2. Autoriser l'installation depuis des sources inconnues sur votre appareil Android.
3. Installer et profiter de l'application.
